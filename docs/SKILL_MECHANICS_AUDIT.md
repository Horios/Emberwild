# 技能機制檢查與分段紀錄

本次範圍：回合制 RPG 常見技能效果；沿用現有技能池、狀態製作器與戰鬥公式，不修改既有技能平衡。

## 節點 1：檢查完成

基準：遊戲 chatgpt-dev `1ac21d6`；平衡器 main `8ce110d`。

| 能力 | 現況 | 本次處理 |
| --- | --- | --- |
| 單體／隨機多目標／全體傷害、屬性、暴擊、破甲、吸血 | 已支援 | 保留原公式 |
| 治療、護盾、溢出治療轉護盾 | 已支援；核心治療固定最低血量、護盾固定自身 | 補核心技能目標及溢出設定 |
| DOT／HOT、比例／固定量、真實傷害 | 狀態製作器已支援，直接技能未完整支援 | 共用既有計算基準，補直接技能設定 |
| 增益／減益、冰凍、變形、恐懼、嘲諷、減速、陷阱 | 已支援；控制以敵方為主 | 保留現有控制設計，避免改動戰鬥流程 |
| 普攻觸發、下次技能增傷、行動提前、技能誘發 | 已支援 | 新效果沿用既有發動鏈 |
| 多段攻擊 | 多目標不等於多段，目前缺少每目標多次結算 | 補每目標命中次數，逐段結算、死亡停止 |
| 傷害／治療／護盾附加狀態 | 主效果與 applyStatus 分離 | 補狀態引用與機率，每次施放每目標判定一次 |
| 淨化減益／驅散增益 | 缺少解除入口與明確分類 | 補可解除狀態分類及數量；被動光環不解除 |
| 復活 | 普通治療只作用存活單位 | 補上場陣亡隊友復活與生命比例，不處理候補 |
| 玩家、夥伴、怪物共用效果 | 怪物共用技能已有部分限制 | 新效果同步實作雙方並驗證匯入／匯出 |

檢查路徑：core-game → numeric-compression-formula → mastery → control-status-summon → status-maker → shared-skill-runtime → companions → induction-runtime。設定由平衡器 classes[].skills 經驗證、匯入轉為執行期陣列及 metadata。
