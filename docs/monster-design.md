# 怪物與 BOSS 關卡設定

- `monsters.catalog` 是唯一的怪物定義來源。`kind` 可為 `normal`、`elite`、`boss`；終局地圖保留 `final`。類型可切換，BOSS 可複製、移動或停用。
- 技能保存既有核心技能 ID。選用人物專用技能時明確開放為 `shared`，保留人物使用資格與原有數值；夥伴專屬技能與不支援怪物的效果不可配置。
- 一般探索使用啟用的 `normal`／`elite`；`boss` 只出現在手動 BOSS 關卡。普通怪的 `enabled` 控制探索，原有停用探索但加入 BOSS 隨從的設定仍保留。
- `baseStats.hp=0`、`baseStats.attack=0`、`baseStats.defense=-1` 表示沿用原有公式；介面顯示留空。指定數值後，仍會套用怪物個別倍率、覺醒與難度處理。
- `maps.catalog[].bossStageMode` 為 `fixed`（舊資料預設）或 `random`。固定模式生成所有配置數量；隨機模式依 `bossStageRandomCount` 決定出場總數。
- 隨機模式首個名額從 BOSS 候選中抽取，其餘名額從完整候選池抽取。每個候選副本的權重為 `spawnWeight`；`bossStageCount` 是最多出場數，不會超額。每次挑戰重新抽取，查看介面與圖鑑不消耗抽取亂數。
- 終局地圖仍保留一名最終首領與等級突破規則，本次未改成隨機終局關卡。

掉落仍以 `balanceSettings.drops.entries` 管理，保存既有物品識別，不能藉由修改中文名稱隱含建立道具。指定裝備使用 `type=equipment`，`key=form:job:slot:index` 或 `boss:region:job`，與全域管理器採用相同識別；指定信物使用 `type=token`、既有信物 ID。原有隨機裝備、來源素材、金幣／經驗與信物全域掉落規則均保留。

設計器從全域管理器搜尋物品，每頁最多 40 件。新建會寫入既有素材價格表、裝備模板、消耗品或信物定義；外觀說明寫入既有圖示設定。新信物預設停用其個別全域隨機掉落資格，透過新增的怪物指定規則取得。單怪修改共用規則時先拆出該怪物來源，不會改動其他怪物的機率或數量；全域掉落頁仍可直接修改共用規則。

驗證只涵蓋新增陣容模式、個別屬性、物品引用、來源拆分、實際生成／發放、元素消耗品與直接受影響的全域管理器流程。
