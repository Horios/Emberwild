# 2026-10-13 程式碼清理與技術債

## 第一階段：修改前審視

基準：遊戲 chatgpt-dev `f18feb1`；main `48d98cc`；私人平衡器 main blob `bfac9fd97ed58f943b8b2dadc474e469cb8ef328`。本次修改只寫入遊戲開發分支，不合併正式版，不公開私人平衡器。

### 架構與資料流

- `index.html` 依序載入 80 個傳統腳本及 32 個 CSS。純模型先載入，`core-game.js` 建立資料／全域函式，後續模組逐層包裝或取代實作。不能以較早的函式當最終規格。
- `js/character` 負責主角、夥伴、成就、隊伍方案；`js/equipment` 負責裝備 UID、待領取、交易及戰鬥裝備快照；`js/skills` 與 `js/combat` 分別處理技能資料／規則和實際戰鬥；`js/world` 處理地圖、掉落、每日與支線。
- 商店、限時道具、生活技能共用隊伍資源；UI、通知及彈窗以相同 state／party 為基礎。50ms tick 同時驅動戰鬥與生活技能；獨立定時器處理儲存、任務刷新、通知及增益。
- 保存鏈：各模組 validate／load／pack／save wrappers → v3 隊伍 JSON → localStorage 主檔／備份。標題控制存檔欄位與保存閘門；Preview 首次複製後使用獨立儲存鍵。v1／v2、裝備、信物及隊伍方案的遷移仍屬有效相容性。
- 平衡鏈：純模型驗證 → core 早期載入 → 後續完整模型再套用 → `exportableBalance()` → 平衡器單檔內嵌契約與 JSON 往返。私人平衡器約 1.95MB，其中含可信任 SVG 目錄；體積不能直接當作廢棄程式證據。
- 已遍歷所有載入 JS 的 AST、外部 CSS 宣告、HTML 資源與 DOM／計時器／事件入口；另檢查測試、工具及部署流程。不同 IIFE 中同名 `validate`、`normalize` 等函式不是同一全域的衝突。

## 節點 1：確認未使用的程式與有效測試

刪除 core 中同作用域被第二個宣告完全取代的第一個 `gearDesc`，及裝備 IIFE 內無任何引用的 `statAdd`／`statMul`。其他同名函式屬不同作用域，不移除。

探索測試改用實際選取存檔流程，避免標題保存閘門使交易假性失敗；強化情境使用測試專用、可越過整數取整門檻的攻擊基值，仍嚴格檢查本場不變／下場提高，出貨數值完全不變。

驗證：探索停止、待領取處置、戰鬥期間背包交易／失敗回復／強化延後、已穿戴鍛造、BOSS 製作共 15／15 通過；語法與 diff 空白檢查通過。

## 節點 2：通知、戰報與補給更新

- 通知計數只在同步建立頁面 HTML 時共用，離開 render 即丟棄；後續任務、領取、存檔及直接呼叫仍讀取即時資料。移除 render 與 AFTER_RENDER 的重複通知更新。一般探索頁每次 render 的任務 readiness 掃描由 4 次降至 2 次。
- 通知元素只寫入變動的 hidden／text／aria 值；同一個同步操作中的多次 save 合併為一個 microtask 更新，不變動保存時間或保存結果。
- 戰報高度觀察器保留，只在高度不同時寫入 CSS 變數。
- 補給倒數抽成 `refreshSupplyStatus()`，早期核心和最終探索 UI 共用；每秒定時器只呼叫最終刷新入口，去除第二輪相同查詢／更新。
- 預設 `npm test` 改用 Node 內建測試探索自動收錄（不依賴 shell wildcard，因此保留 Windows／Node 20 相容性），原有 50 個檔案全部保留，新增檢查不再依賴手動維護長清單。
- 只更新本次修改的五個 script URL 版本，保留 script ID 和載入順序。

節點驗證：通知／生活技能／探索操作 29／29；真實瀏覽器新增 2／2。驗證閒置通知與戰報無多餘 DOM mutation、同輪保存只排一個刷新、每個補給顯示元素每秒只查詢一次；13 個主頁與 3 個彈窗於 1440／390px 的切換、DOM ID 與 Console 均正常。

修改前完整基準：384 項，380 通過、4 失敗、0 跳過。四項失敗全在新探索 fixture：標題保存閘門，以及低攻擊取整門檻；已在節點 1 修正情境，保留交易／回復／強化延後斷言。

修改前後另外使用相同隨機種子比較：所有有效平衡 JSON、初始隊伍存檔、LV1／10／15／30／31／45／60 × 三難度共 21 組探索／八回合戰鬥結果，以及冷啟動讀檔 JSON 完全一致；兩版無執行錯誤。此比對包含既有玩家資源及資料，不靠更動遊戲規則讓結果通過。
