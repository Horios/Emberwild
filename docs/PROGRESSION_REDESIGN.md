## 三人隊實際戰鬥模擬

採六種隊伍：安全＝法師玩家＋保護戰士＋祭司；平衡＝戰士玩家＋法師＋祭司；高輸出＝法師玩家＋攻擊戰士＋弓箭手；高防禦＝防／生命配點戰士＋保護戰士＋祭司；三戰士＝戰士玩家＋攻擊戰士＋保護戰士；雙法師＝法師玩家＋法師＋弓箭手。玩家除高防禦外用攻／攻／生命循環，高防禦用防／生命／防。

## 匯入、存檔與設計器

新增曲線的定義集中在 `progression-model.js`，獨立設計器嵌入完全相同的文字；整合測試會直接比對，避免雙邊公式慢慢偏離。設計器可以修改各職業初值、每級成長、整數階梯、能力點、二轉倍率、怪物、覺醒、難度、XP 與裝備。共用自然成長只作舊 JSON fallback，已隱藏並注明替代路徑；金幣與 EXP 種類／難度倍率的標籤分開。相關匯出 JSON 修改後再匯入遊戲，會測真正最終數值與重載，沒有只測自行計算腳本。

修正了恢復預設會丟失職業整數階梯的問題。設計器內嵌模板的版本標記保留原本壓縮遷移，避免未修改的技能、詞綴等被漏套用；沒有整份覆寫無關設定。

存檔新增 `progressionCurveVersion` 及各隊員的升級需求快照。舊基準內建 v3 存檔按舊需求換算百分比到新需求，保留等級、配點、夥伴、裝備與大致升級進度；因 HP 尺度增加，第一次遷移補滿一次血。新版再次匯入／重新載入不會重複換算或補滿血。含未知自訂舊曲線且沒有快照的存檔，不猜測舊需求；既有自訂平衡照原設定載入。

## 尚存限制與範圍

模擬是固定種子與明確配裝／技能基準，不是所有可能技能、詞綴、寶石與異常自訂平衡的窮舉。高防禦隊會比爆發隊慢，地獄低養成仍可能敗場；夥伴候補不獲 EXP、各自升級與招募依最低出戰等級的規則仍在。玩家二轉仍需原有熟練度與材料，模擬假設已完成所需基本養成。未來同步夥伴等級、獨立固定成長表、技能／AI 重做與跨存檔角色均不在此次實作範圍。
