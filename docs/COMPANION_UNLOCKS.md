# 夥伴顯示與玩家解鎖

夥伴平衡資料的 `availability` 只接受 `visible`（顯示）或 `hidden`（隱藏）。`unlocked`／`locked` 僅作舊資料遷移輸入，不會寫入新版匯出。預設仍只有洛恩、維恩、伊瑟、艾琳、希雅五位顯示，其餘十五位隱藏。

每位夥伴獨立設定 `unlockCondition`，在平衡器「角色與夥伴 → 夥伴解鎖條件」編輯：

| type | 欄位 | 生效方式 |
| --- | --- | --- |
| initial | 無 | 新玩家可招募；五位初始夥伴沿用此設定 |
| achievement | achievementIds | 達成任一綁定成就後寄送指定角色招募券獎勵信，每位只寄一次 |
| ticket | chance、price | 隨機商店每批獨立判定，chance 為 0～1；購買專屬招募券放入背包，使用後解鎖 |

初始開放可直接招募；成就方式先領取信件附件；商店方式直接取得券，使用後開放招募，不自動取得夥伴。遊戲招募視窗顯示條件，成就頁顯示擊殺進度。隱藏夥伴不可招募，也不會出現招募券。已解鎖狀態永久保存，即使後來調整條件也不收回；隱藏設定仍優先限制遊戲顯示。

玩家存檔的 `companionUnlocks` 保存 version=1、unlocked（夥伴 ID）、regions（已開放地區索引）、eliteKills（各地區菁英數量）。不同存檔互不影響。菁英以被擊敗敵人的 region 計數，各難度合計，已結算敵人不重複計入，普通怪與首領不計入。

舊存檔已取得的夥伴會保留並記為已解鎖；可進入地區會依主角門檻補記。最早的舊資料沒有逐地區菁英紀錄，不從總擊殺數推估；前一版已累計的菁英數會遷移到成就系統。BOSS 進度從成就更新後開始累計。

招募券在既有隨機商品批次內追加，受 100 筆商店存檔上限限制；已持有券或已解鎖夥伴停止刷新。既有商品池全部停用時，只要有可刷新的夥伴招募券，仍可刷新商店。價格或條件變動後產生新批次，購買檢查目前設定、金幣及已售狀態，存檔失敗時回復金幣、券數與解鎖進度。

驗證：`node --test tests/companion-unlocks.test.cjs`。另執行夥伴技能、被動、存檔相容與材料售價回歸測試；瀏覽器測試需要可用的 Chromium。
