## 本次修正

1. 冷啟動時，夥伴模組曾在商店、信物與隊伍模組載入前寫入不完整平衡資料，導致重載後設定遺失。改為先讀入、不提前覆蓋原始設定。
2. 舊消耗品時間單位遷移改為處理完整輸入文件，保留後續模組欄位。
3. 角色圖示彈窗關閉後，等指標互動保護完成重繪，再恢復焦點。
4. 補上夥伴被動技能 SVG，與其他名冊技能保持相同尺寸。
5. 平衡器 main 遺漏了開發分支的成長、商品池、限時道具、信物、隊伍與 Lucide 擴充。使用共同祖先進行三方整合，保留 main 的固定姓名、專屬技能、成就、材料售價與進階狀態修改。
6. 同步共用模型與內建預設，保留現有分類導覽；隊伍編輯器移除已廢止的技能點欄位，維持永久解鎖條件。
7. 更新過時測試情境，改用固定姓名、專屬技能、LV1／3／8 及已分組的導覽。不降低所有權、存檔、數值或交易檢查。

## JSON 循環

`tests/balance-roundtrip.test.cjs` 執行六輪，每輪修改 30 個有效欄位及夥伴技能的倍率／解鎖等級：

平衡器檔案匯入 → 匯出 → 遊戲檔案匯入 → 實際值比對 → 儲存 → 冷啟動 → 再比對 → 遊戲匯出回平衡器。

涵蓋職業基礎／成長、核心／輔助技能、裝備、道具、EXP、地圖、怪物、掉落、材料、商品池、新手裝、前綴、狀態、夥伴、評級、被動、信物、隊伍上限與 UI 文字。

另檢查錯誤 JSON、負生命、非整數段數、重複姓名、失效怪物引用、越界掉落率及非法隊伍上限，確認不更動目前設定、玩家存檔或已保存 JSON。

`tests/balance-roundtrip.browser.test.cjs` 另外執行三輪真正瀏覽器操作：修改草泥售價 → 下載 JSON → Preview 選項彈窗檔案匯入 → 實際販售兩份並檢查金額 → 重載遊戲 → 回匯平衡器 → 儲存草稿並重載。
