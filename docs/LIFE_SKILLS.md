# 生活技能測試

- 夥伴使用設計器中的固定角色名稱，移除遊戲內夥伴改名操作；舊存檔的夥伴別名在載入時回復固定名字。主角仍可改名。
- 背包道具頁不顯示零庫存的治療、附魔、抗性與元素增幅藥水；取得後顯示，消耗／販售至零後隱藏。
- 導覽新增「生活技能」，分採集與煉金兩種。採集與製作各自有進度條。
- 生活技能提供目前材料庫存，可查看五種生活材料的說明、數量、單件賣價，指定數量或全部賣出；零庫存保留顯示且禁用販售。紅色草可製作草泥、草泥可製作簡易治療藥水、小蟲標示「尚無用途」。
- 採集對象使用選單，目前僅紅色草可選；採集中禁用選單。採集區移除賣價與用途說明。
- 採集固定每 5 秒取得紅色草 ×1，額外獨立 5% 機率取得小蟲 ×1。紅色草賣價 1 金幣，小蟲賣價 3 金幣；小蟲暫無配方或其他用途。
- 商店分為「生活技能材料／隨機商品／固定商品」三個切換頁面，切換不刷新商品、不停止生活動作；生活材料頁固定供應藥水瓶與清水，各 1 金幣，可購買 1／10 份。沿用材料庫販售功能，兩者賣價亦為 1 金幣，避免套用既有未知材料預設賣價造成買賣套利。
- 加工：紅色草 ×1 → 紅色草泥 ×1。煉金：紅色草泥、清水、藥水瓶各 ×1 → 簡易治療藥水 ×1（既有 `heal_small`，商店預設單價 8 金幣）。加工及煉金暫定各 5 秒／份。
- 採集、探索與製作可同時進行。加工與煉金共用一條製作動作，不可同時進行；須停止後才可切換。探索倍速與探索暫停不影響生活技能計時。
- 動作連續執行，材料在完成時才扣除；不足或達庫存上限時自動停止，不消耗部分配方。停止會清除該次未完成進度。切換頁面會繼續；返回標題、重新讀檔或關閉遊戲會停止，不產生離線收益。
- 產物沿用帳號共用 `materials`／`healingPotions` 的保存、備份與 JSON 匯出匯入。儲存失敗時撤銷該批產物／購買並停止生活動作。

執行 `npm run test:life`：以實際 index.html 載入順序與可控制時鐘驗證上述行為、真正探索行動、進度值、庫存及存檔回復。測試使用 Node 最小 DOM，不能替代瀏覽器版面或原生互動驗證。
