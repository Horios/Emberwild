# 生活技能測試

- 夥伴使用設計器中的固定角色名稱，移除遊戲內夥伴改名操作；舊存檔的夥伴別名在載入時回復固定名字。主角仍可改名。
- 背包道具頁不顯示零庫存的治療、附魔、抗性與元素增幅藥水；取得後顯示，消耗／販售至零後隱藏。
- 導覽新增「生活技能」，分採集與煉金兩種。採集與製作各自有進度條。
- 生活技能提供目前材料庫存，可查看設定中生活材料的說明、數量、單件賣價，指定數量或全部賣出；零庫存保留顯示且禁用販售。紅色草可製作草泥、草泥可製作簡易治療藥水、小蟲標示「尚無用途」。
- 採集對象使用選單，依平衡 JSON 的 `lifeSkills.gathering` 提供項目，預設為紅色草；採集中禁用選單。採集區移除賣價與用途說明。
- 預設採集每 5 秒取得紅色草 ×1，額外獨立 5% 機率取得小蟲 ×1。紅色草賣價 1 金幣，小蟲賣價 3 金幣；小蟲暫無配方或其他用途。
- 商店分為「生活技能材料／隨機商品／固定商品」三個切換頁面，切換不刷新商品、不停止生活動作；生活材料頁固定供應藥水瓶與清水，各 1 金幣，可購買 1／10 份。沿用材料庫販售功能，兩者賣價亦為 1 金幣，避免套用既有未知材料預設賣價造成買賣套利。
- 加工：紅色草 ×1 → 紅色草泥 ×1。煉金：紅色草泥、清水、藥水瓶各 ×1 → 簡易治療藥水 ×1（既有 `heal_small`，商店預設單價 8 金幣）。加工及煉金預設各 5 秒／份、成功率 100%。
- 採集、探索與製作可同時進行。加工與煉金共用一條製作動作，不可同時進行；須停止後才可切換。探索倍速與探索暫停不影響生活技能計時。
- 動作連續執行，材料在完成時才扣除，失敗仍消耗材料但不產出；不足或達庫存上限時自動停止，不消耗部分配方。停止會清除該次未完成進度。切換頁面會繼續；返回標題、重新讀檔或關閉遊戲會停止，不產生離線收益。
- 產物沿用帳號共用 `materials`／`healingPotions`／`consumables` 的保存、備份與 JSON 匯出匯入。儲存失敗時撤銷該批產物／購買並停止生活動作。

- 平衡器「採集與煉金」分類提供「採集產物」「煉金產物」頁，可新增、刪除項目，設定各自秒數、成功機率與產物數量；產物可為材料或既有消耗道具。採集額外產物獨立判定，保留原本小蟲掉落規則。
- 每份配方最少 1、最多 5 種材料，每種單獨設定數量，也可消耗既有道具；重複材料須合併數量。秒數最少 0.05 秒，機率介於 0～100%，數量為正整數。JSON 使用毫秒及 0～1 機率，舊 `periodMs`／`bugChance` 遷移到各項目，匯出僅保留有效來源。

執行 `npm run test:life`：涵蓋既有生活流程、自訂產物、五種材料、機率邊界、存檔回復，以及真實瀏覽器表單編輯、JSON 下載／匯入、獨立計時及手機版面。
