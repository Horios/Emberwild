# 基底評級與裝備詳細資訊

修改基準：`chatgpt-dev` 的 `196ac7a14a6c6ba655183b4c5cb19a5aab426084`。本次調整評級與資訊呈現，沒有調整預設裝備平衡。

## 實際資料來源與載入順序

以 `index.html` 的最後有效定義為準：

1. `core-game.js` 提供裝備、穿戴、比較、強化及存讀檔基礎流程。
2. `equipment-stat-source.js` 將裝備固定效果正規化，處理舊魔力詞綴相容，取消早期隱藏護甲與 BOSS 基底效果。
3. `equipment-identity.js` 最後決定前後綴、BOSS 三條固定效果、`powerTier`、`gearStatBreakdown`、主要角色能力與裝備摘要。
4. `numeric-compression-formula.js` 載入有效平衡設定，包裝角色能力取整；`affix-pool.js` 決定實際隨機詞綴池。
5. `starter-pack.js` 後載入，透過 `itemForm` 提供新手裝固定效果及成長；`class-growth.js`、`companions.js`、`progression-runtime.js` 沒有重新覆寫裝備來源計算。

裝備地區階級 `tier`（1～12）與基底強度 `powerTier`（1～10）是不同欄位。評級只依 `powerTier`，不使用地區、角色等級、最高詞綴品質或強化值。

## 摘要與來源

摘要顯示裝備自身可直接提供的攻擊、生命、防禦與固定速度。效果規則與完整來源移入預設摺疊的「詳細數值來源」。未提供直接數值的來源仍保留，顯示「—」。

| 效果 | 裝備摘要 | 原有效果 |
| --- | --- | --- |
| gearAtkPct／gearHpPct／gearDefPct | 依此裝備原始基底計入 | 保留 |
| flatAttack／flatHp／flatDefense／speed | 計入固定加值 | 保留 |
| 隨機詞綴 type 0／1／2 | 計入攻擊／生命／防禦 | 保留 |
| attackPct／hpPct／defensePct、type 15 | 不換算；來源顯示 — | 角色最終百分比仍套用 |
| 暴擊、穿透、抗性、首領增傷、元素、技能、冷卻、前移、掉寶等 | 不換算；來源顯示 — | 角色／戰鬥原流程仍生效 |

實際順序保持原有規則：

1. `rawTierStats` 讀取 `balanceSettings.equipment.baseStats`，依地區階級取得原始基底。
2. `EmberwildProgression.gearStats` 套用裝備自身百分比，取整，再套用 `equipmentPowerSystem.strength.multipliers` 與強化倍率，逐步取整。
3. 角色能力原本另行加入的固定效果、隨機直接詞綴，現在也列入裝備摘要；角色結算仍按原位置加入一次。
4. 角色總能力百分比與戰鬥效果留在角色／戰鬥結算。

`equipmentStatContributions` 從上述實際基底結果建立顯示來源，不更動 `gearBaseStats` 的回傳意義。每個來源列出增量；同類百分比與小數固定值的取整差額依來源順序分配。所有來源整數相加必須等於摘要。

例：原始攻擊 30、裝備基底攻擊 +30%、角色總攻擊 +10%：摘要為「攻擊 +39」，基底列 +30，裝備百分比列 +9，角色百分比列 —。角色總攻擊 +10% 仍在穿戴後生效。

展開後保留原效果規則、基底、各條固定效果、前後綴、兩條隨機詞綴、基底倍率與強化貢獻；新手裝成長整合進同一份來源列表，沒有另設隱藏零值開關。列表底部附加「已計入上方」及「— 不代表效果失效」的固定說明。

## 必要的計算修正

既有前後綴設定允許 `gearHpPct`／`gearDefPct`，但舊 `baseStatPct` 只讀取基底或 BOSS 效果，導致合法設定被忽略。本次改為讀取完整裝備身分效果，使這兩類前後綴能進入既有裝備基底流程。沒有擴充詞綴類型或變更其計算規則。

預設前後綴沒有使用這兩類裝備百分比；336 組修改前角色能力快照在預設設定下完全一致。

內部 Tier、JSON 結構、倍率、抽選權重與平衡器欄位維持原有設定。舊重鑄道具描述在玩家 UI 邊界轉換用語；不改寫匯出的自訂描述。`Emberwild-Balance` 不需要因顯示映射而更動數值或欄位，現有 JSON 匯入／匯出回歸測試仍通過。
