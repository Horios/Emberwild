# 遊戲內信箱

成就頁僅顯示達成紀錄、進度及篩選，不再顯示「成就與獎勵通知」或成就領獎區塊，也不為一般成就跳出通知。

當可顯示且未解鎖的夥伴達成任一綁定成就，系統寄送一封指定角色招募券獎勵信。信件包含達成成就說明與一張指定夥伴招募券附件。每位夥伴每個存檔只寄一次；已完成成就之後才綁定時也可補寄。隱藏夥伴不寄信；已持有券或已解鎖的夥伴不重複發券。

頂部信封按鈕開啟信箱彈窗，紅色數字顯示未讀或未領附件的郵件數。打開信件標為已讀，可單封領取附件，也可全部領取。領取後招募券存入「背包 → 道具」，使用後才開放招募。已領取信件保留紀錄，附件不能重複領取。

寄信、讀信與領取狀態隨玩家存檔保存。寄信提示與戰報紀錄只在成功存檔後出現，讀檔不重播既有郵件提示。領取或全部領取若寫入失敗，回復券數、信件已讀及已領取狀態；任何附件超過库存上限時整批保留。

舊版已直接獲得的券留在背包，已發獎紀錄保留，不再補寄同一獎勵。`achievements` 遷移至 version=3，保留已讀標記及擊殺數、完成成就、夥伴發獎紀錄與券庫存；原通知欄位不再保存。新 `mailbox`（version=1）包含 serial、messages。信件保存 id、rewardKey、subject、body、at、read、claimed、attachments；招募券附件保存 type、companionId、quantity、name。非法信箱在啟動或匯入時拒絕，不取代原始存檔。

若领信前透過其他方式解鎖夥伴，仍可領取附件，再使用既有的重複券金幣轉換機制。

測試：`node --test tests/mailbox.test.cjs`。
