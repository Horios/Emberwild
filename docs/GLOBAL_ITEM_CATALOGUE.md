# 全域道具管理器

平衡器「道具與經濟 → 全域道具管理器」是道具共同資料的入口。取得來源與用途分開，沿用 items、equipmentForms、companionTokens、lifeSkills、shopSettings 與既有掉落／經濟設定，不建立第二份庫存。

## 分類、搜尋與排序

- 用途階層：裝備／素材／消耗品，各有完整子分類，可修改最多五層分類與用途標籤。
- 多選來源：採集、煉金／加工、商店、怪物、分解、鍛造、任務／成就、信箱、初始配發。
- 可同時篩選用途、設定狀態、職業、部位、武器種類、元素、地區、色彩模板與售價範圍。
- 搜尋名稱、ID、說明、用途、來源與標籤；空格分隔的關鍵字須同時符合。
- 排序：分類、名稱、ID、售價、購買單價、部位、地區、來源數、用途引用數；可選遞增／遞減。
- 每頁 40 個道具。篩選／排序、選取道具與裝備預覽會在目前瀏覽器保存；跳轉後返回保留狀態。

## 每個道具的設定

基本資料、分類、圖示、個別顏色／色彩模板、說明、售價、販售資格、所有取得設定與用途引用共用一個道具識別。

普通裝備能力定位到指定裝備變體；BOSS 模板定位到實際 BOSS 專屬詞綴；信物定位到指定信物。藥水、限時增益券與重鑄石分別定位到各自能力設定頁。

裝備與信物可以設定個別售價與固定分解產物；留空／不使用個別產物時沿用共用規則。預覽按品質、階級、強化值計算，信物固定第 1 階；空的個別分解清單表示分解不給產物。個別產物會取代基本鍛鐵、粉塵與額外產物，不重複加總。

素材改名使用顯示別名，保留原庫存鍵與所有配方引用。BOSS 難度素材保留各自庫存鍵；不得合併普通、困難、地獄材料。

所有道具區分 0 售價與不可販售。寶石預設維持不可販售；明確啟用後才出現出售控制。出售與分解儲存失敗會回復庫存；出售會檢查金幣保存上限。

生活商店可以上架自訂素材；基本清水與藥水瓶保留。鍛鐵／粉塵的購買、產出與煉金投入使用原共用資源欄位。素材無論取得來源皆可用於配方；寶石與裝備仍依既有系統使用，不因分類變更而變成可投入材料。

## 新增、刪除與版本

可新增素材；裝備、信物、治療藥水、限時增益券透過相應完整設定入口管理。自建素材只有在沒有來源、用途或核心庫存引用時才可刪除；刪除定義保留玩家舊庫存。

目前預設資料涵蓋 328 個道具定義／生成變體、46 條用途分類路徑。編輯或新增來源後數量會自動更新。

可匯出／匯入同一份平衡 JSON，沿用發布管理與版本差異。新經濟／顯示資料的 `itemDetailsVersion:2` 與自訂商店材料的 `lifeShopMaterialsVersion:1` 相容性會在正式版發布前檢查。

## 驗證

新增的模型、管理器與實際交易測試涵蓋完整分類、去重、多條件篩選／排序、跳轉與返回、個別售價、分解、寶石販售、原資源庫煉金、JSON round-trip、舊存檔與儲存失敗回復。既有道具、色彩、生活技能、信物、平衡 JSON 與發布服務回歸測試維持通過。

本次環境未提供 Chromium，可操作瀏覽器畫面與依賴 Chromium 的測試仍未驗收；使用 Node 執行的實際遊戲與管理器資料流程測試不替代瀏覽器版面驗收。
