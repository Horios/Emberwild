# 每日委託與支線設計

本次只更新 `chatgpt-dev` 測試版與私有平衡器；正式遊戲 `main` 不合併。

## 手札現況與相容性

- 委託為帳號共用，不使用夥伴／角色選擇。
- 每日最多一張，使用 Asia/Taipei 日曆日，00:00 換日；付費刷新與常駐重複募集停用。
- 原有 `wolves`、`witch`、`stars` 支線 ID 與完成紀錄保留。
- 既有當日委託保留到下一次換日，匯入設計、切換地圖或角色不能重抽。
- 新每日委託保存完整需求與獎勵快照。已完成、未符合條件、每日抽取停用等狀態都會保存，當日空池不重抽。
- 舊的三張看板在升級時只遷移一次；原先支線進度與累計委託次數保留。

## 唯一有效設計來源

`balanceSettings.quests.design`：`version: 1`、`daily.enabled`、`daily.entries[]`、`side[]`。

舊 `quests.board`、`quests.repeat`、`quests.side` 只用於舊 JSON 遷移；平衡器不再把它們顯示為可用任務控制。

| 欄位 | 用途 |
| --- | --- |
| id | 固定任務 ID，修改名稱不清除玩家的完成紀錄；複製會產生新 ID |
| title / description | 任務名稱與說明／劇情 |
| enabled | 控制新每日抽取，或支線是否開放 |
| weight | 每日符合條件的任務之相對抽選權重 |
| minLevel / maxLevel | 出現與交付等級條件；maxLevel=0 表示不限 |
| mapIndices | 空陣列不限；每日依抽取時所在地，支線依交付時所在地 |
| prerequisites | 需要全部完成的支線 ID；禁止自我引用、循環及不存在的前置 |
| objectives | 1～16 項全部達成的需求；庫存型可選消耗或只檢查持有 |
| rewards | 固定資源、每階資源、EXP、寶石、材料、藥水、道具及裝備 |

需求類型：材料、治療藥水、道具、指定怪物累計擊殺、全怪物累計擊殺、主角等級、地區開放、BOSS 累計擊殺、菁英累計擊殺。
指定怪物以既有掉落素材名稱識別；地區 BOSS／菁英依成就紀錄，各難度合計。擊殺和地區需求是累計紀錄，不要求接取後重打。

每日材料 key=`@currentMap` 依當日所在地圖抽取普通怪物素材。每日需求支援數量範圍及每地區階增量；支線需求固定數量。需求相同類型／品項不能重複。

裝備 tier=0 沿用地區階、slot=-1 隨機部位、job=-1 隨機職業。`choice=gearOrGems` 以 gearChance 抽出裝備或寶石，其餘獎勵固定發放。每日在抽取時就結算並保存，支線在交付時結算。

EXP 發給主角，夥伴依既有等級同步規則成長。裝備空間與資源上限不足會阻止交付；儲存失敗會原地回復庫存、獎勵、等級、夥伴、隊伍配點與任務紀錄。

## 平衡器

新增「委託與支線」分類，分為「每日委託設計」「支線設計」「教學與舊商店設定」。提供搜尋、啟用／停用篩選、新增、複製、刪除、排序、多需求與多獎勵表單、地圖／前置勾選和設計預覽。
刪除仍被其他任務或技能引用的支線會阻止操作；停用可保留任務 ID 和歷史紀錄。

遊戲手札提供可進行／未解鎖／已完成／全部篩選，顯示鎖定原因、逐項進度與消耗規則，數字提醒只計入目前能交付的任務。

## 共用契約與驗證

遊戲 `js/world/quest-design-model.js` 和平衡器 `quest-design-model-v1` script 必須完全相同。
`npm run test:quests` 驗證換日、舊存檔、多需求、支線前置、完整獎勵、失敗回復、快照驗證、六輪 JSON 往返與實際表單／下載／匯入／交付／重載。
`npm test` 為全專案回歸；環境需提供既有 Playwright 與 Chromium。
