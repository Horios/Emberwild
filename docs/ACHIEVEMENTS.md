# 地區成就與夥伴招募券

遊戲側欄新增「成就」，依地區、成就類型、達成狀態篩選，顯示進度條、綁定的夥伴招募券與最近 100 筆通知。預設顯示目前地區，避免一次列出所有地區的階段。

- 每個地區有一項開放成就，依主角的地圖進入門檻判定，已開放後永久保留。
- 菁英／BOSS 各自以 50、100、150……1000 為目標，共 20 階段，各地區獨立，各難度合計。
- 終局首領計入該地區 BOSS；不提供無菁英或已停用 BOSS 的地區所對應擊殺成就。
- 只計入真正結算的被擊敗敵人，以敵人 region 為準；已結算的敵人不重複計數。
- 所有成就自動完成，不需要手動領獎。達成與招募券通知在成功存檔後顯示，同時記錄於成就頁和戰報。

平衡器「夥伴解鎖條件」可選初始開放、達成指定成就或商店招募券。成就可複選；達成任一項即發送指定角色招募券，每位夥伴每個玩家存檔只發一次。後來綁定已完成成就會補發；隱藏夥伴不發券，日後顯示可補發。原本已解鎖的角色保留狀態，不重複發券。

成就券與商店券都放入「背包 → 道具 → 夥伴招募券」。使用後才開放指定角色招募，不隨機抽取角色，也不直接加入隊伍。已持有券或已解鎖的角色停止刷新商店招募券。購買或使用時若存檔失敗，金幣、券數及解鎖狀態回復。

資料：`achievements`（version=1）保存 eliteKills、bossKills、completed、rewardCompanions、tickets、notifications、noticeSerial。成就 ID 如 `region-0-open`、`region-0-elite-50`、`region-0-boss-1000`。夥伴條件為 `{type:"achievement",achievementIds:[...]}`。

相容：舊 `region` 條件轉為地區開放成就；舊 `elite` 條件轉為對應階段（非 50 倍數向上到下一階，最高 1000）。原有 `companionUnlocks.eliteKills` 遷移為新成就菁英數；舊資料沒有地區 BOSS 數，從 0 開始。舊版購買券已立即解鎖的角色保留。玩家存檔互不影響；非法成就／券資料在匯入及啟動時拒絕，原始資料保留。

驗證：`node --test tests/achievements.test.cjs tests/companion-unlocks.test.cjs`，涵蓋每 50 一階至 1000、指定地區分類、重複結算、券只發一次、複選／補發／隱藏／已持有角色、庫存使用、存檔失败回復、通知重載、舊存檔及設計器 JSON。

防重複：已解鎖夥伴的券仍可使用，消耗一張並顯示提示視窗，轉換為該夥伴 `duplicateTicketGold` 金幣（預設 100，平衡器解鎖條件頁可調整）。存檔失敗回復券數與金幣；若金幣會超過上限則保留券。
