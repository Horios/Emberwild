# 頂部工具彈窗與數字提醒

信箱、成就、選項從側欄移至頂部，使用既有 Lucide SVG 的信封、獎牌、齒輪圖示。三者開啟彈窗，不切換目前主頁面；可用關閉按鈕或 Escape 關閉。彈窗依遊戲既有規則暫停戰鬥，篩選與領取會更新彈窗內容。

「兌換碼」僅保留在選項彈窗內，背包分頁列移除入口。

紅色數字：

- 信箱：未讀或未領附件的信件，每封只算一次；讀過但尚未領附件仍提醒。
- 成就：新達成且未看過的成就；開啟成就彈窗把當時已完成的紀錄標為已讀。之後新達成會再提醒，在成就彈窗中直接達成則視為已讀。
- 背包：待领取裝備＋尚未決定的洗鍊結果，同件 ID 不重複計入。不將一般已領取裝備視為待處理。
- 委託手札：可交付的看板委託、未完成支線與重複募集，每個任務入口只算一次，不把可重複交付次數當作任務數。已交付、過期、材料不足，或背包滿而无法領裝備的委託不計入。

選項的「數字提醒開關」提供上述四種提醒各自開關，預設全開。關閉只隱藏紅色數字，不影響資料或操作。設定保存在該玩家存檔的 `numberReminders`，讀檔保留，其他存檔獨立。

`achievements` 升級為 version=3，增加 `readCompleted`。舊存檔既有完成紀錄視為已讀，避免更新後把全部歷史成就當作新提醒。設定及已讀標记在寫入失敗時回復；非法設定／已讀紀錄在匯入前拒絕。

頂部按鈕不在定時刷新時重建；只更新數字及按鈕狀態。彈窗內的按鈕與選單沿用操作保護，避免戰鬥刷新打斷點擊。
