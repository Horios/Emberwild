# 主角技能圖示與鑲嵌

主角技能依需求角色等級由低到高分組，同級 SVG 圖示並列。點選後僅在右側顯示該技能說明、永久條件、學習與槽位配置；窄畫面改為上下排列。

重繪時保留 `.player-skill-page` 的水平與垂直捲動位置。學習、裝配、卸下與寶石更換仍走既有隊伍交易與存檔流程，所選技能在操作後保留；切換職業或隊伍時清除選取。

主動與普攻觸發技能仍各有一個寶石槽。赤焰石、疾風石、共鳴石共用本地 Lucide `gem` SVG，以紅、綠、紫色區分。寶石按鈕顯示現有庫存，已鑲嵌寶石顯示於槽位，並可卸下；未學習、庫存為零、探索中與其他職業預覽均不可新增鑲嵌。輔助技能維持既有無寶石槽設定。
